
# 📦 Inventory Management System — Java

A simple, console-based Inventory Management System developed using Java. This project helps manage product records, track stock quantities, update product details, and calculate the total inventory value.

## 🚀 Features

- ➕ **Add Product:** Add new products with ID, name, quantity, and price.
- 📋 **View Products:** Display all products in the inventory.
- 🔍 **Search Product:** Find a product using its unique ID.
- ✏️ **Update Product:** Update the quantity and price of a product.
- 🗑️ **Delete Product:** Remove a product from the inventory.
- 💰 **Inventory Value:** Calculate the total value of all available stock.
- 🚪 **Exit:** Safely exit the application.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Data Structure:** ArrayList
- **Input Handling:** Scanner
- **Concepts:** Object-Oriented Programming (OOP), Classes, Objects, Methods, Loops, and Conditional Statements

## 📋 Requirements

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

### 2. Navigate to the Project Folder

```bash
cd Inventory-Management-System
```

### 3. Compile the Java Program

```bash
javac InventoryManagementSystem.java
```

### 4. Run the Application

```bash
java InventoryManagementSystem
```

## 📊 How It Works

1. Launch the application.
2. Select an operation from the menu.
3. Enter the required product information.
4. Manage product records using the available options.
5. Calculate the total inventory value whenever needed.
6. Exit the application when finished.

### Example

Suppose the inventory contains:

| Product | Quantity | Price per Unit |
|---|---:|---:|
| Keyboard | 10 | ₹500 |
| Mouse | 5 | ₹300 |

**Total Inventory Value:**

```text
(10 × 500) + (5 × 300) = ₹6,500
```
